# MAVI Design References

These folders contain authoritative visual references for the MAVI frontend.

## Rules

1. Reference images are the visual source of truth for MAVI.
2. Before implementing or visually modifying a screen, inspect the relevant
   reference images in this directory.
3. Do not replace the reference design with a generic SaaS design.
4. Reproduce the visual language as closely as technically possible.
5. Preserve existing MAVI functionality, API behavior and information
   architecture.
6. Do not change backend functionality for visual work unless explicitly
   requested.
7. Blue + White is the primary MAVI brand theme.
8. The frontend must ultimately support:
   - Blue + White
   - Light
   - Dark
   - System
9. Landing-page references define the landing-page visual direction.
10. Application references define the visual direction of their respective
    application screens.
11. 3D references define the visual direction for the MAVI 3D experience.
